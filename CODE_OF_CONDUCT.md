# Code of Conduct

## The short version

Be kind. Be direct. Assume good faith.

## Details

- **Disagreement is welcome, disrespect is not.** Argue with the idea, not the person.
- **Critique the code, review the reasoning.** "This approach has a subtle
  failure mode when X" beats "this is wrong."
- **Report problems to the project owner first** before escalating anywhere
  public.
- **This is a small project run by one person.** The project owner may ignore,
  decline, or remove contributions, comments, or participants at any time,
  especially where conduct is off.
- Scope: this applies to everything project-related — the repository, its
  issues and discussions, and any chat spaces connected to it.

If someone is bothering you, tell the project owner directly.
